# Rygate Tactical Solutions website

Static website starter prepared for zero-cost deployment.

## Files
- `index.html` main single-page website
- `styles.css` responsive styling
- `script.js` menu and enquiry email helper
- `assets/rygate-logo.jpg` supplied logo
- `assets/rygate-company-profile-2026.pdf` supplied company profile

## Initial features
- Responsive navigation and layout
- Service and sector overview
- Quotation form that prepares an email to sales@rygatesecurity.co.za (the visitor must send the email)
- WhatsApp click-to-chat link (number should be verified as WhatsApp-enabled)
- CV application mail link (visitor attaches their CV manually)
- Company profile PDF download
- Telephone and email links

## Deploy
Publish this directory via GitHub Pages. For the initial site, GitHub Pages can host these static files. Domain DNS setup will be required to use rygatesecurity.co.za. Do not change DNS until the current records and hosting situation are checked.

## Limitations to address in a future iteration
- Forms are not server-submitted: the quotation form opens a mail draft.
- No database/admin dashboard/authentication yet.
- Careers applications are email-based; applicants must attach CV manually.
- The hero uses an external Unsplash image and Google Fonts; for fully self-contained hosting, replace these with locally stored assets.
- Review image rights, email deliverability, privacy notices, and company details before launch.
